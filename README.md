# Swasthyogi: Rapid Crisis Response & Coordination

**Swasthyogi** is a high-reliability crisis management platform built to synchronize emergency response within the decentralized hospitality ecosystem. It eliminates information silos by creating an intelligent bridge between distressed guests, on-site personnel, and first responders.

## 🚩 The Problem
Hospitality venues face unpredictable emergencies where critical information (guest medical history, precise room location, real-time status) is often fragmented. This "information silo" delays life-saving interventions and fractures communication during the most critical seconds of a crisis.

## 💡 The Solution
Swasthyogi solves this by pre-synchronizing guest wellness profiles with hospitality infrastructure.
- **Instant SOS**: User-triggered emergency protocols with < 200ms synchronization.
- **Precision Tracking**: Automatically links SOS alerts with Room Numbers and Hotel Wings.
- **AI Guidance**: Immediate multi-lingual first-aid instructions via Gemini AI while help is en route.
- **Verified Access**: Secure password-based protocols for sharing sensitive guest data with responders.

## 🏗 Architecture & Tools
- **Frontend**: Flutter (Cross-platform performance)
- **Backend**: Firebase Cloud (Auth, Firestore, App Check)
- **Intelligence**: Google Gemini Pro (Symptom analysis & active guidance)
- **Development**: **Google Antigravity** (Advanced Agentic AI-driven engineering)
- **Security**: AES-encrypted secure storage & Play Integrity

## 🛠 Setup & Installation
1.  **Clone**: `git clone https://github.com/your-repo/swasthyogi.git`
2.  **Config**: Place your own `google-services.json` in `android/app/` (Omitted from repo for security).
3.  **Environment**: Add your `GEMINI_API_KEY` to a `.env` file in the root (Omitted from repo for security).
4.  **Launch**: `flutter pub get` && `flutter run`
